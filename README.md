# AgentBoard

Your Claude Code sessions at work above the Dock: what they tell each other, decide and need from you. It reads only what your sessions already write.

**[Download for Mac](https://github.com/bloonguyen1207/agentboard/releases/latest)** · [Guide](https://bloonguyen1207.github.io/agentboard/)

- For Macs with Apple silicon, with Claude Code.
- Free for one folder. Pro, a one-time licence for every folder, is coming.

## Install

1. Download the `.dmg` from the [latest release](https://github.com/bloonguyen1207/agentboard/releases/latest) and drag AgentBoard to Applications. It replaces an older Agentboard.app.
2. Open it. The first time, macOS blocks it: choose **Open Anyway** in System Settings › Privacy & Security.
3. AgentBoard lives in the menu bar. Open its panel and follow a folder; its sessions appear on the strip.

With npm instead, on Node 24 or later: `npm install -g` the `.tgz` from the release.

AgentBoard can't update itself. Turn on **Check for new versions** in Settings › App › Updates and it tells you when a new release is out.

This repository holds AgentBoard's releases and its guide. The source is not public.
